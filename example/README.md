# Demo de saia_skills

App mínima que recorre el catálogo: categorías, búsqueda, cambio de idioma
y lectura del markdown de una habilidad.

```bash
flutter run
```

Sirve además de comprobación: consumido desde otra app, los assets viven
bajo `packages/saia_skills/assets/`. Si el prefijo se resolviera mal, la
lista saldría vacía en lugar de fallar.
